# 星海萌芽 · 八兵种造舰修复版

> Star Seed Sprout — 一个单文件太空舰队策略游戏

**不是拼数量，而是编对舰队。**

"星海萌芽"是一个零依赖、单文件（`index.html`）的太空舰队建造与星区争夺策略游戏。
双击 `index.html` 即可开玩，不需要安装任何东西，也不需要联网。

---

## 玩法核心

游戏围绕一条 10 个切片（切片 01 → 切片 10）的成长路径展开：

> **复盘 → 修正 → 再实战**

每一局失败都带有收益 —— 战场通讯会给出失败归因（兵力判断失误 / 护盾不足 / 舰队编成错误），
这些归因会转换成下一局的复盘目标，驱动你把短板练成优势。

### 主要系统

| 模块 | 说明 |
| --- | --- |
| **SHIPYARD / 星系造舰** | 在己方星系消耗资源建造舰船 |
| **SECTOR INTELLIGENCE / 星系情报** | 查看 8 种舰船属性与兵种克制关系，标注"克制 / 被克制" |
| **实时星区争夺** | 点击己方星系，再点击相邻目标星系派出舰队 |
| **编队交战复盘** | 每场交战生成战报：兵力对比、守军护盾、预测受阻原因 |
| **TRANSMISSIONS / 战场通讯** | 关键事件流，实时播报战况 |
| **COMMANDER / 指挥官** | XP 与等级成长，有迹可循 |
| **战前战术流派** | 突破 / 兵力判断、防御 / 高压应变、调度 / 战术节奏 |
| **里程碑挑战** | 切片 10 的终局挑战 |

### 八兵种

护卫舰、巡洋舰、战列舰、航空母舰、电子战舰、维修舰等共 8 种舰船，
存在明确的克制链（例如"重甲主炮，碾压巡洋舰"），因此 **编队结构比舰队规模更重要**。

### 战术要点

- 派出舰队前先看 **星系情报** 里的兵种克制，再决定编队
- 舰队航速由 **最慢的舰船** 决定
- 守军有 **防御护盾** 时，硬堆数量往往无效，需要电子战舰一类针对性单位
- 维修舰可在战后恢复，适合长线推进

## 运行方式

```bash
# 方式一：直接双击
open index.html

# 方式二：起一个本地静态服务（iOS / 移动端调试用）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

---

## 技术说明

- **单文件**：HTML + CSS + 原生 JavaScript 全部内联在 `index.html` 里，无构建步骤、无外部依赖
- **无后端**：所有状态都在内存中，进度不落盘
- **响应式**：`100dvh` + flex 布局，适配桌面与移动端
